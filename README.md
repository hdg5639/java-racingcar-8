# java-racingcar-precourse

## 1. 과제

### 초간단 자동차 경주 게임 구현

- 여러 대의 자동차가 주어진 횟수만큼 **전진 또는 멈춤**을 반복한다.
- 각 자동차는 **이름**을 가질 수 있으며, 전진 시 **이름과 함께 결과를 출력**한다.
- 자동차 이름은 **쉼표(,)** 로 구분하며, **최대 5자 이하**만 허용한다.
- 사용자는 **이동 시도 횟수**를 직접 입력한다.
- 전진 조건은 **0~9 사이의 난수 중 4 이상일 때 전진**한다.
- 경주 종료 후 **최종 우승자(또는 공동 우승자)** 를 출력한다.
- 잘못된 입력값이 들어오면 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

---

## 2. 구현할 기능
- [ ] **자동차 이름 입력 기능**
    - 이름 입력
    - 입력값을 `Car` 객체 리스트로 변환
    - 이름 길이 검증 (5자 이하)
    - 잘못된 입력 시 예외 처리

- [ ] **시도 횟수 입력 기능**
    - 시도 횟수 입력

- [ ] **자동차 이동 조건 구현**
    - `move()` 메서드와 같은 이동 함수 구현
    - 0~9 난수 생성 후 4 이상일 때 전진

- [ ] **자동차 이동 로직 구현**
    - 각 시도마다 모든 자동차 이동
    - 이동 결과 출력

- [ ] **우승자 판별 기능**
    - 최종 이동 거리 기준 최대 이동 거리 계산
    - 공동 우승자 처리
---

## 3. 요구 사항

- 들여쓰기(Indent)는 **최대 2단계까지만 허용**
- **삼항 연산자 사용 금지**
- **하나의 함수는 한 가지 역할만 수행**
- `Randoms`, `Console` API 사용
    - 난수 생성: `pickNumberInRange()`
    - 입력: `readLine()`

## 주의

- “시도할 횟수”는 전체 게임의 라운드 수를 의미
  - 한 번 입력한 시도 횟수 값으로 **모든 자동차가 동일한 횟수만큼 이동 시도**.
- 예를 들어 사용자가 `5`를 입력했다면, 모든 자동차는 총 **5번의 이동 시도**를 하며  
  각 라운드마다 한 번씩 전진 여부를 판정
- “게임 총 횟수”와 “자동차 이동 횟수”는 **동일한 값**을 사용
